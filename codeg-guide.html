codeg

TUI Coding Agent Manager — Multi-Agent Task Orchestration with opencode Backend

What is codeg?

A terminal-based task manager that orchestrates opencode coding agents. Decompose complex tasks into sub-tasks, execute them with two-phase (coding → verification) workflow, and judge results with LLM.

Quick Start

export OPENAI_API_KEY="sk-xxx"
export OPENAI_BASE_URL="https://api.deepseek.com"
export CODEG_LLM_MODEL="deepseek-chat"
go run ./cmd/codeg/

    participant T as 🖥 TUI
    participant C as 🎮 Controller

    Note over U,L: Phase 1 — Planning
    U->>T: Press 'p'
    T->>O: opencode run (plan prompt)
    O-->>T: JSON sub-task list
    T->>U: Show plan UI (edit/confirm)
    U->>T: Press Enter

    Note over U,L: Phase 2 — Coding
    U->>T: Select sub-task, press 'r'
    T->>C: StartSubTaskCoding
    C->>O: opencode run (coding prompt)
    loop Streaming
        O-->>T: agent_message_chunk
        O-->>T: tool_use (bash, read, write)
    end
    O-->>T: turn_complete
    T->>L: Judge: COMPLETED / STUCK / FAILED
    L-->>T: COMPLETED ✅

    Note over U,L: Phase 3 — Verification
    T->>C: StartSubTaskVerification
    C->>O: opencode run (verify prompt)
    O-->>T: verification output
    T->>L: Judge: PASSED / FAILED
    L-->>T: PASSED ✅
    T->>U: Auto-start next sub-task

4. Keybindings

KeyModeAction
nDashboardCreate new task (title + objective)
bDashboardBind working directory to selected task
pDashboardPlan mode — decompose task into sub-tasks via ACP
rDashboardRun coding agent on selected/next planned sub-task
fDashboardForce verification on selected sub-task
cDashboardCancel currently running agent
dDashboardDelete selected task (confirmation required)
EnterPlanConfirm sub-task plan → create all sub-tasks
ePlanEdit selected sub-task
+/-PlanAdd / remove sub-task
↑/↓AllNavigate tasks or sub-tasks
TabDashboardSwitch focus: tasks → sub-tasks → agent output
1/2/3DashboardFocus panel 1 (tasks), 2 (sub-tasks), 3 (agent)
qDashboardQuit (kills subprocesses)
